OpenShell namespace, SCC, and rendered gateway values prepared for the AgentOps demo.

This release ({{ .Release.Name }}, namespace {{ .Release.Namespace }}) does NOT install
the gateway itself — it only creates namespace "{{ .Values.namespace }}", the privileged
SCC RoleBinding, and a ConfigMap of rendered values. The gateway is installed separately
via `make -C deploy deploy-openshell-oci` (upstream OCI chart, release "openshell",
image tag {{ .Values.openshell.image.tag }}) in namespace "{{ .Values.namespace }}".
{{- if .Values.openshift.scc.privilegedSandbox }}
SCC:       privileged → {{ include "agentops-openshell.sandboxSA" . }} (post-install hook, namespace {{ .Values.namespace }})
{{- end }}

Verify:
  oc -n {{ .Values.namespace }} rollout status statefulset/openshell
  oc -n {{ .Values.namespace }} get pods,secret | grep -E 'NAME|openshell'
{{- if .Values.openshift.scc.privilegedSandbox }}
  oc -n {{ .Values.namespace }} get rolebinding | grep privileged
{{- end }}

Connect (from your workstation):
  oc -n {{ .Values.namespace }} port-forward svc/openshell 8080:8080
  openshell gateway add https://127.0.0.1:8080 --local --name openshift
  make -C deploy openshell-sync-mtls   # required after gateway add --local
  openshell status
