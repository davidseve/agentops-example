OpenShell gateway deployed for the AgentOps demo.

This is a single Helm release ({{ .Release.Name }}, namespace {{ .Release.Namespace }})
that renders both this wrapper's OpenShift extras (privileged SCC RoleBinding, Route)
and the upstream OpenShell gateway itself (subchart dependency, image tag
{{ .Values.openshell.image.tag }}) together — see deploy/Makefile's `deploy-openshell`
target and Chart.yaml's `dependencies:` block for the pinned upstream version.
{{- if .Values.openshift.scc.privilegedSandbox }}
SCC:       privileged → {{ include "agentops-openshell.sandboxSA" . }} (namespace {{ .Release.Namespace }})
{{- end }}

Verify:
  oc -n {{ .Release.Namespace }} rollout status statefulset/openshell
  oc -n {{ .Release.Namespace }} get pods,secret | grep -E 'NAME|openshell'
{{- if .Values.openshift.scc.privilegedSandbox }}
  oc -n {{ .Release.Namespace }} get rolebinding | grep privileged
{{- end }}

Connect (from your workstation — also run automatically by
`make -C deploy deploy-openshell` / `./scripts/launch-openclaw.sh`):
  make -C deploy openshell-register-gateway   # GATEWAY_NAME=ocp by default
  openshell status
  ./scripts/launch-openclaw.sh               # creates sandbox if needed
